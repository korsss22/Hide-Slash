# 게임 이름
Hide&Slash

## 🎮 소개
Hide & Slash는
사물로 변신해 위장하고 점점 줄어드는 자기장 속에서
최후의 생존을 노리는 P2P based 멀티플레이 액션 게임입니다.

기존 Prop Hunt의 단순 은신 구조에서 벗어나
전투 시스템과 자기장 시스템을 결합하여 후반 강제 교전을 유도합니다.

## 🛠 기술 스택
- Unity
- C#
- Steamworks
- mirror

## 🔥 핵심 시스템
- <b>자기장 시스템</b>  
  - 시간에 따라 안전구역 축소  
  - Zone 데미지 기반 강제 이동 유도  
  - 후반부 교전 유도  
  
- <b>변신 시스템</b>  
  - 주변 오브젝트로 실시간 변신  
  - 위장 ↔ 전투 전환 구조 설계  
    
- <b>전투 시스템</b>  
  - 근접 공격 기반 전투  
  - 쿨타임 및 리스크 설계
